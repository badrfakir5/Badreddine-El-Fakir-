# Badreddine El Fakir — Personal Portfolio

A personal portfolio website built from scratch to showcase my software engineering projects, university coursework and professional profiles.

I’m studying BSc Software Engineering at Solent University. This project also documents my progress in web development as I build features using HTML, CSS and JavaScript and expand towards a full-stack application.

## Features

- Homepage introducing my background and portfolio.
- Projects page showcasing university coursework and assessments.
- Contact page with email, LinkedIn and GitHub links.
- Dark and light themes with a saved browser preference.
- Responsive project cards and navigation.
- Navigation highlighting the current page.
- Accessible theme controls with descriptive labels and keyboard focus styles.

Some featured repositories are private and require permission to view their source code.

## Technologies

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantic content |
| CSS3 | Layout, responsive styling and themes |
| JavaScript | Theme switching and browser interactions |
| localStorage | Saving the selected theme |
| Git and GitHub | Version control and source hosting |

## Project Structure

```text
index.html       Homepage
projects.html    Projects and coursework
contact.html     Contact details and professional profiles
styles.css       Shared styles and theme colours
script.js        Theme switching and preference storage
```

## Run Locally

1. Clone this repository using its GitHub clone URL.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.

The current version runs in the browser without a build step or package installation.
